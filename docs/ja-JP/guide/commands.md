# コマンド

```bash
npx zcf [command] [options]
```

1 つのコマンドのオプションは `zcf <command> --help` で確認できます。すべてのコマンドが次のオプションを受け付けます。

| オプション | 意味 |
|------------|------|
| `-l, --lang <lang>` | 表示言語。`en` または `zh-CN`。`ZCF_LANG` とシステムのロケールより優先されます。 |
| `-h, --help` | ヘルプを表示します。 |
| `-v, --version` | バージョンを表示します。 |

## `zcf`

ターミナルでコマンドを付けずに実行すると、`zcf tui` と同じく [ターミナルエディター](./ui) が開きます。出力先がターミナルでない場合は、代わりにヘルプを表示します。

## `zcf tui`

ターミナルエディターで設定を編集します。

| オプション | 意味 |
|------------|------|
| `--file <path>` | 設定ファイル。デフォルト: `~/.ufomiao/zcf/zcf.json`。 |

## `zcf ui`

ブラウザーで設定を編集します。ZCF は `127.0.0.1` で小さなサーバーを起動してページを開き、<kbd>Ctrl</kbd>+<kbd>C</kbd> を押すまで動き続けます。

| オプション | 意味 |
|------------|------|
| `--file <path>` | 設定ファイル。 |
| `--port <port>` | 待ち受けるポート。デフォルト: 空いている任意のポート。 |
| `--no-open` | アドレスを表示するだけで、ブラウザーを開きません。 |

サーバーにはこのマシンからしか接続できません。表示されるアドレスには、このサーバーの実行ごとのランダムなトークンが含まれ、トークンの無い API リクエストは拒否されます。[ターミナル UI と Web UI](./ui#web-ui) を参照してください。

## `zcf init`

エディターを開かず、1 回のコマンドで設定を作ります。プリセットからプロバイダーを埋め、ツールと一緒に導入するものを選び、ファイルを保存してから、`zcf apply` と同じプランと適用を実行します。

```bash
zcf init --preset 302ai --api-key sk-... --tools claude-code,codex --skills git-commit --yes
```

オプションを一切付けずに実行した場合は、空の設定を書き込まずにエディターへの案内だけを表示します。

| オプション | 意味 |
|--------|---------|
| `-p, --preset <id>` | [プロバイダープリセット](./providers)の id。プロバイダー全体を埋めます。キーは `--api-key` で渡します。 |
| `-k, --api-key <key>` | プロバイダーの API キー。`--preset` と併用するか、設定にすでにプロバイダーが必要です。 |
| `-t, --tools <tools>` | 選択するツールをカンマ区切りで。`zcf plan` と同じ書式です。 |
| `--skills <skills>` | 導入する内蔵スキルをカンマ区切りで。 |
| `--agents <agents>` | 導入する内蔵エージェントをカンマ区切りで。 |
| `--styles <styles>` | 導入する出力スタイルをカンマ区切りで。 |
| `--default-style <style>` | ツールがデフォルトで使う出力スタイル。 |
| `--extras <extras>` | 周辺ツール: `magpie`（`magpie:client` と同じ）、`magpie:cli`、`ccline`。 |
| `-m, --mirror <mirror>` | 設定の `mirror` として保存し、この実行でも経由します。 |
| `-l, --lang <lang>` | 設定の `language` として保存し、この実行でもその言語で表示します。 |
| `-y, --yes` | 保存後に適用します。付けない場合、ZCF はファイルを保存しプランを表示するだけです。 |
| `--file <path>` | 設定ファイル。無ければ作成し、あればキー単位でマージし、コメントとレイアウトを残します。 |

すべての id はファイルに触れる前に検査されます。不明なプリセット、ツール、スキル、エージェント、スタイル、周辺ツールは、選択肢の一覧とともにエラーになり、何も書き込まれません。`--skills` や `--agents` のような選択は設定の既存内容とマージされ、`--tools` のようなリストは置き換えます。保存されたファイルは `zcf apply` と同じ手順で適用されるため、`-y, --yes` の判断もそこで働き、ツールを 1 つも選んでいない設定は同じエラーで停止します。

## `zcf plan`

何も変更せずに、`zcf apply` が行う内容を表示します。各ツールのステップ、ZCF 自身が編集する各ファイルの diff、ツールが使えないプロバイダープロトコルなどの通知が表示されます。

| オプション | 意味 |
|------------|------|
| `--file <path>` | 設定ファイル。 |
| `--tools <tools>` | 設定の `tools` の代わりに対象とするツール ID をカンマ区切りで指定します（例: `--tools claude-code,codex`）。 |
| `--mirror <mirror>` | この実行で使う `official` または `china`。[ミラー](./mirrors) を参照してください。 |

`claude mcp add-json` のようにツール自身のコマンドを実行するステップは、コマンドとして表示されます。何を書き込むかはツールが決めます。

## `zcf apply`

選択したツールのうち足りないものをインストールし、設定を書き込みます。`zcf plan` と同じオプションに加えて、次を受け付けます。

| オプション | 意味 |
|------------|------|
| `-y, --yes` | 適用します。付けない場合、ZCF はプランを表示するだけで何も変更しません。 |

ツールは並列に適用されます。あるステップが失敗すると、そのツールの残りのステップはそれに依存するためスキップされ、他のツールは処理を続けます。最後のまとめに、失敗した内容とバックアップの場所が表示されます。いずれかのステップが失敗した場合、終了コードは `1` です。

## `zcf update`

選択したツールを、`claude update`、`codex update`、`opencode upgrade`、`pi update --self` など、それぞれのアップデーターで更新します。専用のアップデーターが無いツールは `npm install -g` で更新します。ただし、インストール済みのバージョンが npm の最新版であればスキップします。アップデーターが失敗したとき、そのパッケージが npm でインストールされたものなら（ZCF は `npm ls -g` で確認します）、`npm install -g <pkg>@latest` にフォールバックします。ネイティブインストールにはこのフォールバックを行わないため、npm が二番目のコピーを残すことはありません。インストールされていないツールは通知を出してスキップします。更新後、ZCF は更新した各ツールのバージョンを確認し、新しいバージョンになったか、すでに最新だったかを表示します。

| オプション | 意味 |
|------------|------|
| `--file <path>` | 設定ファイル。読むのは `tools` と `mirror` だけです。 |
| `--tools <tools>` | 設定の `tools` の代わりに更新するツール。指定した場合、設定ファイルは無くても構いません。 |
| `--mirror <mirror>` | この実行で使う `official` または `china`。 |

## `zcf uninstall`

ツールをアンインストールし、ZCF が書き込んだ設定を取り除きます。`zcf apply` と同様、まずプランを表示し、`-y, --yes` を付けなければ何も変更しません。

```bash
zcf uninstall claude-code codex --yes
```

各ツールはそれぞれの経路でアンインストールします。npm でインストールされたものは `npm uninstall -g`、OpenCode は npm 以外のインストールに対して独自の `opencode uninstall --keep-config --keep-data` を使います。npm パッケージが無いインストール（Claude Code と Codex のネイティブインストール、Cursor CLI）は、インストーラーが置いたファイルを、削除前にバックアップフォルダーへコピーしてから削除します。Windows ではこれらのファイルは `claude.exe` と `codex.exe` で、Cursor CLI は `%LOCALAPPDATA%\cursor-agent` フォルダー全体として削除します。インストール元を判断できないツールは通知とともにスキップします。インストールしたときの方法でアンインストールしてください。

ZCF が取り除くのは自分が書き込んだ設定だけです。プロバイダールート（`zcf` エントリ、それを指すモデル選択、dsh のルートパッチ）。Claude Code の `ANTHROPIC_*` 環境変数と Gemini CLI の `.env` のキーは、設定ファイルが書き込む値のまま残っているときにだけ取り除きます。同名でも値が違う設定はユーザー自身のものかもしれないため、通知とともに残します。MCP サーバー、スキル、ツール自身の設定と区別できないものはそのまま残り、ファイル全体を削除することもありません。アンインストール後、これらのツールは設定ファイルの `tools` から除かれるため、後の `zcf apply` で再インストールされることはありません。また、ツールのコマンドが実際に応答しなくなったかも確認します。

| オプション | 意味 |
|------------|------|
| `--file <path>` | `tools` リストを整理する設定ファイル。 |
| `-y, --yes` | アンインストールします。付けない場合、ZCF はプランを表示するだけです。 |

## `zcf mirror [mirror]`

引数なしの場合、使用中のミラーと、その設定がどこから来ているか（`ZCF_MIRROR`、設定ファイル、デフォルト）を表示します。`official` または `china` を指定すると、設定ファイルの `mirror` に保存します。[ミラー](./mirrors) を参照してください。

| オプション | 意味 |
|------------|------|
| `--file <path>` | 設定ファイル。 |

## `zcf switch <profile>`

適用する[プロバイダープロファイル](./config#profiles)を切り替えます。id または表示名で指定したプロファイルのプロバイダーを、最上位の `provider` にコピーします。書き込む前にファイルをバックアップします。ツールには何も書き込まれないため、切り替えたプロバイダーを渡すには `zcf apply --yes` を実行してください。

| オプション | 意味 |
|------------|------|
| `--file <path>` | 設定ファイル。 |

## `zcf backup [command]`

`~/.ufomiao/zcf/backups/` のバックアップを管理します。ZCF はファイルを変更・削除する前に元のバージョンをそこへコピーし、実行ごとに時刻の名前のフォルダーに保存します。

| コマンド | 意味 |
|---------|---------|
| `list`（デフォルト） | バックアップを新しい順に一覧表示します: id、作成の理由、ファイル数。 |
| `restore <id>` | 指定したバックアップのファイルを元に戻します。`-y, --yes` なしでは内容を表示するだけです。復元の前に現在のファイルを新しいバックアップへコピーするため、そのバックアップを復元すれば元に戻せます。 |
| `prune` | 最新の `--keep <n>`（デフォルト 20）を超えた古いバックアップを削除します。最新の 1 つは常に残ります。`-y, --yes` なしでは削除対象を表示するだけです。 |

| オプション | 意味 |
|--------|---------|
| `-y, --yes` | 確認なしで復元・削除します。 |
| `--keep <n>` | 削除時に残すバックアップ数。 |

## `zcf ccu`

[ccusage](https://ccusage.com) で Claude Code の使用量と費用を確認します。ZCF は `npx -y ccusage@latest` を起動してターミナルをそのまま渡し、終了コードを透過します。ccusage は自分の CLI と自分の更新方式を保ちます。ZCF は転送するだけで、PATH に `npx`（Node.js）が必要です。ccusage 自身は通常どおり npm からダウンロードされ、ZCF のミラー設定は適用されません。

## 終了コード

| コード | 意味 |
|--------|------|
| `0` | 完了、または何もすることが無い。 |
| `1` | ステップが失敗した、ツールが選択されていない、または不明なツール ID などコマンドラインが誤っている。 |
| `2` | 設定ファイルが無い、または無効。 |

`zcf update --tools` は設定ファイル無しで実行でき、`zcf mirror <mirror>` は設定ファイルが無ければ作成します。
