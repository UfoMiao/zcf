# コマンド

```bash
npx zcf [command] [options]
```

1 つのコマンドのオプションは `zcf <command> --help` で確認できます。すべてのコマンドが次のオプションを受け付けます。

| オプション | 意味 |
|------------|------|
| `--lang <lang>` | 表示言語。`en` または `zh-CN`。`ZCF_LANG` とシステムのロケールより優先されます。 |
| `-h, --help` | ヘルプを表示します。 |
| `-v, --version` | バージョンを表示します。 |

## `zcf`

ターミナルでコマンドを付けずに実行すると、`zcf tui` と同じく [ターミナルエディター](./ui) が開きます。出力先がターミナルでない場合は、代わりにヘルプを表示します。

## `zcf tui`

ターミナルエディターで設定を編集します。

| オプション | 意味 |
|------------|------|
| `--file <path>` | 設定ファイル。デフォルト: `~/.ufomiao/zcf/zcf.json`。 |

## `zcf ui`

ブラウザーで設定を編集します。ZCF は `127.0.0.1` で小さなサーバーを起動してページを開き、<kbd>Ctrl</kbd>+<kbd>C</kbd> を押すまで動き続けます。

| オプション | 意味 |
|------------|------|
| `--file <path>` | 設定ファイル。 |
| `--port <port>` | 待ち受けるポート。デフォルト: 空いている任意のポート。 |
| `--no-open` | アドレスを表示するだけで、ブラウザーを開きません。 |

サーバーにはこのマシンからしか接続できません。表示されるアドレスには、このサーバーの実行ごとのランダムなトークンが含まれ、トークンの無い API リクエストは拒否されます。[ターミナル UI と Web UI](./ui#web-ui) を参照してください。

## `zcf plan`

何も変更せずに、`zcf apply` が行う内容を表示します。各ツールのステップ、ZCF 自身が編集する各ファイルの diff、ツールが使えないプロバイダープロトコルなどの通知が表示されます。

| オプション | 意味 |
|------------|------|
| `--file <path>` | 設定ファイル。 |
| `--tools <tools>` | 設定の `tools` の代わりに対象とするツール ID をカンマ区切りで指定します（例: `--tools claude-code,codex`）。 |
| `--mirror <mirror>` | この実行で使う `official` または `china`。[ミラー](./mirrors) を参照してください。 |

`claude mcp add-json` のようにツール自身のコマンドを実行するステップは、コマンドとして表示されます。何を書き込むかはツールが決めます。

## `zcf apply`

選択したツールのうち足りないものをインストールし、設定を書き込みます。`zcf plan` と同じオプションに加えて、次を受け付けます。

| オプション | 意味 |
|------------|------|
| `-y, --yes` | 適用します。付けない場合、ZCF はプランを表示するだけで何も変更しません。 |

ツールは並列に適用されます。あるステップが失敗すると、そのツールの残りのステップはそれに依存するためスキップされ、他のツールは処理を続けます。最後のまとめに、失敗した内容とバックアップの場所が表示されます。いずれかのステップが失敗した場合、終了コードは `1` です。

## `zcf update`

選択したツールを、`claude update`、`codex update`、`opencode upgrade`、`pi update --self` など、それぞれのアップデーターで更新します。専用のアップデーターが無いツールは `npm install -g` で更新します。ただし、インストール済みのバージョンが npm の最新版であればスキップします。インストールされていないツールは通知を出してスキップします。更新後、ZCF は更新した各ツールのバージョンを確認し、新しいバージョンになったか、すでに最新だったかを表示します。

| オプション | 意味 |
|------------|------|
| `--file <path>` | 設定ファイル。読むのは `tools` と `mirror` だけです。 |
| `--tools <tools>` | 設定の `tools` の代わりに更新するツール。指定した場合、設定ファイルは無くても構いません。 |
| `--mirror <mirror>` | この実行で使う `official` または `china`。 |

## `zcf mirror [mirror]`

引数なしの場合、使用中のミラーと、その設定がどこから来ているか（`ZCF_MIRROR`、設定ファイル、デフォルト）を表示します。`official` または `china` を指定すると、設定ファイルの `mirror` に保存します。[ミラー](./mirrors) を参照してください。

| オプション | 意味 |
|------------|------|
| `--file <path>` | 設定ファイル。 |

## 終了コード

| コード | 意味 |
|--------|------|
| `0` | 完了、または何もすることが無い。 |
| `1` | ステップが失敗した、ツールが選択されていない、または不明なツール ID などコマンドラインが誤っている。 |
| `2` | 設定ファイルが無い、または無効。 |

`zcf update --tools` は設定ファイル無しで実行でき、`zcf mirror <mirror>` は設定ファイルが無ければ作成します。
