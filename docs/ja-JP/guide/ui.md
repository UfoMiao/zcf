# ターミナル UI と Web UI

ZCF には [設定ファイル](./config) を編集するエディターが 2 つあります。ターミナル版（`zcf` または `zcf tui`）とブラウザー版（`zcf ui`）です。チェック内容は同じで、ページも同じものが揃っています。Web のサイドバーも同じセクション分け（初期設定 / ワークフロー / 追加ツール / バックアップ）で表示します。好みに合わせて選んでください。

どちらも下書きを編集します。保存するまで何も書き込まれず、保存時も変更した部分だけが書き込まれます。ZCF を開いたままテキストエディターでファイルを編集しても、同じキーを ZCF 側で変更していなければ、その編集は残ります。

セッション中の最初の保存では、書き込む前に設定を `~/.ufomiao/zcf/backups/<時刻>/` へコピーします。

## ページ

| ページ | できること |
|--------|------------|
| Agent tools（エージェントツール） | 設定するエージェントツールにチェックを入れます。各行にツールのインストール状況とバージョンが表示されます。 |
| Provider（プロバイダー） | [プリセット](./providers) から始めるか、名前、API キー、エンドポイント、モデルを入力します。**Remove the provider**（プロバイダーを削除）で設定から取り除きます。プロバイダーを[プロファイル](./config#profiles)として保存して切り替えることもできます。 |
| MCP servers（MCP サーバー） | サーバーの追加、編集、名前変更、削除を行います。種類を `stdio` と `http` の間で切り替えると、もう一方の種類にしか無いフィールドはリセットされます。 |
| Skills（スキル） | ZCF 内蔵スキルを選び、コミュニティ索引を検索して他のスキルを見つけ、独自のソースと、ソースごとにインストールするスキルを追加できます。 |
| Settings（設定） | ZCF 自身の設定で、どのツールの設定にも書き込まれません。[設定言語](./config#configlanguage) と [ダウンロードミラー](./mirrors) です。`ZCF_MIRROR` が設定されている場合はページにその旨が表示されます。変数が設定されている間は変数が優先され、ここで保存した値は変数を外した後に有効になります。 |
| Apply（適用） | 保存済みの設定のプランを、各ファイルの diff とともに確認してから適用します。 |
| Workflows（ワークフロー） | スキルとエージェントの組である既製のワークフローバンドルにチェックを入れたり、エージェント、内蔵・コミュニティスキル、自分の MCP サーバーを組み合わせた独自のバンドルを作ったりできます。出力スタイルもここにあります。インストールするものとデフォルトを選びます。 |
| Agents（エージェント） | エージェントに対応するツールにインストールされる内蔵エージェントを選びます。 |
| Extras（追加ツール） | コーディングツールの横に同伴ツールを追加します。magpie ローカルゲートウェイ（`client` または `cli`）と CCometixLine ステータスバーです。 |
| Backup（バックアップ） | ZCF が変更前にとったバックアップからファイルを戻し、古い実行を整理します。このページは下書きではなく保存済みのファイルを操作します。 |

ターミナル UI のページ一覧はセクションに分かれています — Init config（初期設定）、Workflows（ワークフロー）、More tools（他のツール）、Backup（バックアップ）— 各セクションに見出しが付き、ページにはリスト全体を通した番号が付きます。ナビのどこからでもその数字を押せばジャンプできます。Web UI のサイドバーは同じページをフラットに並べます。

フィールドは入力中にチェックされます。エラーのある設定は保存できず、問題点がフィールドの横に表示されます。

シークレットは隠されたままです。どちらのエディターでも、API キーと MCP の環境変数・ヘッダーの値は編集中 `*` で表示されます。

エディターの表示言語は英語と簡体字中国語のため、ページ名やボタン名は英語で示しています。

## 言語

名前が似た 2 つの設定があり、役割が違います。

- **UI 言語** は ZCF 自身の表示言語です。どちらのエディターもヘッダーから切り替えます。ターミナル UI は <kbd>L</kbd>、Web UI はパスの横のセレクターで、即座に単独で保存され、未保存の下書きの他の変更には触れません。設定ファイルの [`language`](./config#language) で、`auto` は Web UI ではブラウザーの言語、ターミナル UI ではシステムのロケールに従います。`--lang` または `ZCF_LANG` を付けると 1 回の実行の間は固定され、切り替えは無効になります。
- **設定言語** は適用後にツール自身が使う言語です。設定ページのフィールドで、独自の言語設定を持つツールにのみ書き込まれます。[`configLanguage`](./config#configlanguage) を参照してください。

`zcf plan` などのコマンド出力は `--lang` か `ZCF_LANG` に従い、どちらの設定も読みません。

## ターミナル UI

| キー | 操作 |
|------|------|
| <kbd>↑</kbd> <kbd>↓</kbd>（または <kbd>k</kbd> <kbd>j</kbd>） | 行やページの間を移動します。 |
| <kbd>0</kbd>–<kbd>9</kbd> | 数字が示すページへジャンプ、またはその行を実行せずに選択します。 |
| <kbd>Enter</kbd> | ページを開く、フィールドを編集する、編集を確定する、またはアクションを実行します。 |
| <kbd>←</kbd> <kbd>→</kbd> または <kbd>Space</kbd> | MCP サーバーの種類などの選択肢を切り替えます。 |
| <kbd>x</kbd> | 選択した項目を削除します。 |
| <kbd>Esc</kbd> または <kbd>←</kbd> | 戻る、または編集を取り消します。 |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | 保存します。入力中のフィールドは先に <kbd>Enter</kbd> で確定してください。 |
| <kbd>L</kbd> | UI 言語を切り替えます。どのページからでも使え、即座に保存されます。 |
| <kbd>q</kbd> | ページ一覧から終了します。未保存の変更がある場合は 2 回押します。 |

リストの行には、画面に見えている内容に対する番号が付きます。`› 3 Label` なら、ウィンドウがどこまでスクロールしていても <kbd>3</kbd> がその行を選びます。

ターミナル UI は画面全体を占め（終了時に元に戻ります）、マウスにも対応します。行をクリックすると選択して <kbd>Enter</kbd> と同じ操作を実行し、左のページ一覧をクリックするとページを切り替え、ホイールで選択を動かせます（Apply ページではプランをスクロールします）。<kbd>Shift</kbd> を押しながらクリックすると、ターミナル本来の方法でテキストを選択できます。端末が 23 行未満だとバナーは 1 行に折りたたまれ、UI は画面全体を保ちます。ウィンドウが低いとき、ページ一覧は自分のセクションの中でスクロールします。

**Apply** ページでは、<kbd>Enter</kbd> で適用、<kbd>r</kbd> で再計画、矢印キーでスクロールします。プランは保存済みのファイルから作られるため、未保存の変更があると先に保存するよう求められます。

MCP サーバーの引数は、シェルと同じ書き方で 1 行に入力します。空白を含む引数は引用符で囲みます: `--header "Authorization: Bearer x"`。

## Web UI

```bash
npx zcf ui              # ブラウザーを開く
npx zcf ui --no-open    # アドレスを表示するだけ
npx zcf ui --port 4567  # ポートを固定する
```

サーバーは `127.0.0.1` でのみ待ち受け、自分自身のアドレス宛てのリクエストにだけ応答します。表示されるアドレスの末尾は `#token=...` です。ページはすべての API リクエストにこのトークンを付けて送るため、他のサイトのページがサーバー経由で設定を読んだり変更したりすることはできません。サーバーの実行中は、このアドレスをパスワードと同じように扱ってください。サーバーは <kbd>Ctrl</kbd>+<kbd>C</kbd> で停止します。

ページが設定を編集するため、ブラウザーは設定そのものを受け取ります。プランと適用結果はマスクされた状態で返ります。表示されるのは ZCF が編集する各ファイルの diff（シークレットはマスク済み）だけで、ファイル全体は表示されません。長いシークレットは `sk-***Xy` のように先頭 3 文字と末尾 2 文字が残るので、どれなのか見分けられます。

<kbd>Ctrl</kbd>+<kbd>S</kbd>（macOS では <kbd>⌘</kbd>+<kbd>S</kbd>）は保存ボタンと同じく保存します。同じサーバーに 2 つのタブを開いた場合、各タブは自分の変更だけを保存します。
