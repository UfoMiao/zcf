# 终端与网页界面

ZCF 为[配置文件](./config)提供两个编辑器：终端里的（`zcf` 或 `zcf tui`）和浏览器里的（`zcf ui`）。两者校验相同，页面也一一对应——网页侧栏同样按节分组（初始化配置 / 工作流 / 其他工具 / 备份与恢复），按需选择即可。

两者编辑的都是草稿。保存前不会写入任何内容，保存时也只写入你改动的部分。ZCF 打开期间如果你在文本编辑器里修改了文件，只要没有在 ZCF 中改动同样的键，你的修改都会保留。

每次会话中的第一次保存，会先把配置复制到 `~/.ufomiao/zcf/backups/<时间>/` 再写入。

## 页面

| 页面 | 在这里做什么 |
|------|--------------|
| Agent 工具 | 勾选要配置的 Agent 工具。每一行显示工具是否已安装以及版本。 |
| 供应商 | 从[预设](./providers)开始，或填写名称、API 密钥、接口地址和模型。“移除供应商”会把它从配置中删除。还可以把供应商存为[配置档案](./config#profiles)，随时切换。 |
| MCP 服务 | 添加、编辑、重命名和删除服务。在 `stdio` 和 `http` 之间切换类型时，只属于另一种类型的字段会被清空。 |
| 技能 | 勾选 ZCF 内置技能，搜索社区索引发现更多技能，或添加自己的来源并为每个来源选择要安装的技能。 |
| 设置 | ZCF 自身的设置，不会写入任何工具的配置：[配置语言](./config#configlanguage)和[下载镜像](./mirrors)。如果设置了 `ZCF_MIRROR`，页面会提示：变量存在时以它为准，这里保存的选择在变量取消后生效。 |
| 应用 | 查看已保存配置的计划和每个文件的 diff，然后应用。 |
| 工作流 | 一键勾选预置的技能与子代理组合，也可以自定义组合，引用子代理、内置或社区技能以及你的 MCP 服务。输出风格也在这里：选择要安装的风格和默认风格。 |
| 子代理 | 选择要安装到支持子代理的工具的内置子代理。 |
| 附加工具 | 在编程工具之外安装伴随工具：magpie 本地网关（`client` 或 `cli`）与 CCometixLine 状态栏。 |
| 备份 | 从 ZCF 修改文件前的备份恢复文件，并清理旧备份。该页操作的是已保存的文件，与草稿无关。 |

终端界面的页面列表按节分组——初始化配置、工作流、其他工具、备份与恢复——每节有自己的标题，页面在全列表中带编号：在导航里按对应数字即可跳转。网页界面的侧栏以平铺方式列出相同页面。

字段在输入时即时校验。有错误的配置无法保存，页面会在对应字段旁显示问题。

敏感信息始终隐藏。在两个编辑器中，API 密钥以及 MCP 环境变量和请求头的值在编辑时都显示为 `*`。

## 语言

两个设置听起来相近，作用不同：

- **界面语言**决定 ZCF 自己显示什么。两个编辑器都从顶部切换——终端界面按 <kbd>L</kbd>，网页界面用路径旁的选择框——并立即单独保存，不会动到草稿里其他未保存的修改。它对应配置里的 [`language`](./config#language)；`auto` 在网页界面跟随浏览器语言，在终端界面跟随系统语言。`--lang` 或 `ZCF_LANG` 会为单次运行固定语言，此时切换被禁用。
- **配置语言**决定应用后各工具自身使用什么语言。它是「设置」页的一个字段，只有拥有自己语言设置的工具才会收到。见 [`configLanguage`](./config#configlanguage)。

`zcf plan` 等命令输出跟随 `--lang` 或 `ZCF_LANG`，与这两个设置无关。

## 终端界面

| 按键 | 操作 |
|------|------|
| <kbd>↑</kbd> <kbd>↓</kbd>（或 <kbd>k</kbd> <kbd>j</kbd>） | 在行或页面之间移动。 |
| <kbd>0</kbd>–<kbd>9</kbd> | 跳到数字对应的页面，或只选中对应行而不执行。 |
| <kbd>Enter</kbd> | 打开页面、编辑字段、确认编辑或执行操作。 |
| <kbd>←</kbd> <kbd>→</kbd> 或 <kbd>空格</kbd> | 切换选项，例如 MCP 服务的类型。 |
| <kbd>x</kbd> | 删除选中的项目。 |
| <kbd>Esc</kbd> 或 <kbd>←</kbd> | 返回，或取消编辑。 |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | 保存。正在输入的字段请先按 <kbd>Enter</kbd> 确认。 |
| <kbd>L</kbd> | 切换界面语言，任意页面可用，并立即保存。 |
| <kbd>q</kbd> | 在页面列表中退出。有未保存的修改时需按两次。 |

列表中的行按屏幕上可见的内容编号：`› 3 标签` 表示按 <kbd>3</kbd> 选中该行，无论窗口滚动到哪里。

终端界面占满整个终端窗口（退出后恢复原样），并支持鼠标：点击某一行即选中并执行 <kbd>Enter</kbd> 对应的操作，点击左侧页面列表切换页面，滚轮移动选择，在应用页则滚动计划输出。按住 <kbd>Shift</kbd> 点击可以用终端自己的方式选择文本。窗口不足 23 行时，横幅会折叠成一行，界面依然完整铺满全屏；窗口较矮时页面列表会在自己的节内滚动。

在“应用”页，<kbd>Enter</kbd> 执行应用，<kbd>r</kbd> 重新生成计划，方向键用于滚动。计划基于已保存的文件生成，因此有未保存的修改时，页面会提示你先保存。

MCP 服务的参数在一行中输入，规则与 shell 相同。含空格的参数需要加引号：`--header "Authorization: Bearer x"`。

## 网页界面

```bash
npx zcf ui              # 打开浏览器
npx zcf ui --no-open    # 只打印地址
npx zcf ui --port 4567  # 固定端口
```

服务器只监听 `127.0.0.1`，并且只响应发往自身地址的请求。打印出的地址以 `#token=...` 结尾。页面的每个 API 请求都会带上这个令牌，因此其他网站的页面无法通过该服务器读取或修改你的配置。服务器运行期间，请像对待密码一样对待这个地址。按 <kbd>Ctrl</kbd>+<kbd>C</kbd> 停止服务器。

浏览器会拿到配置本身，因为页面需要编辑它。计划和应用结果返回时都已遮盖：你看到的是 ZCF 所修改的每个文件的 diff，其中敏感信息已遮盖，永远不会看到整个文件。较长的密钥会保留开头 3 个和结尾 2 个字符（例如 `sk-***Xy`），方便你分辨是哪一个。

<kbd>Ctrl</kbd>+<kbd>S</kbd>（macOS 上为 <kbd>⌘</kbd>+<kbd>S</kbd>）与“保存”按钮作用相同。在同一个服务器上打开两个标签页时，每个标签页只保存自己的修改。
