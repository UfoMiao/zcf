# 终端与网页界面

ZCF 为[配置文件](./config)提供两个编辑器：终端里的（`zcf` 或 `zcf tui`）和浏览器里的（`zcf ui`）。两者页面相同、校验相同，用哪个都可以。

两者编辑的都是草稿。保存前不会写入任何内容，保存时也只写入你改动的部分。ZCF 打开期间如果你在文本编辑器里修改了文件，只要没有在 ZCF 中改动同样的键，你的修改都会保留。

每次会话中的第一次保存，会先把配置复制到 `~/.ufomiao/zcf/backups/<时间>/` 再写入。

## 页面

| 页面 | 在这里做什么 |
|------|--------------|
| 工具 | 勾选要配置的工具。每一行显示工具是否已安装以及版本。 |
| 供应商 | 从[预设](./providers)开始，或填写名称、API 密钥、接口地址和模型。“移除供应商”会把它从配置中删除。 |
| MCP 服务 | 添加、编辑、重命名和删除服务。在 `stdio` 和 `http` 之间切换类型时，只属于另一种类型的字段会被清空。 |
| 技能 | 勾选 ZCF 自带的技能，或添加自己的来源并为每个来源选择要安装的技能。 |
| 设置 | ZCF 自身的设置，不会写入任何工具的配置：界面语言和[下载镜像](./mirrors)。如果设置了 `ZCF_MIRROR`，页面会提示：变量存在时以它为准，这里保存的选择在变量取消后生效。 |
| 应用 | 查看已保存配置的计划和每个文件的 diff，然后应用。 |

字段在输入时即时校验。有错误的配置无法保存，页面会在对应字段旁显示问题。

敏感信息始终隐藏。在两个编辑器中，API 密钥以及 MCP 环境变量和请求头的值在编辑时都显示为 `*`。

## 语言

界面语言取自配置里的 `language`，在「设置」页选择；`auto` 在网页界面跟随浏览器语言，在终端界面跟随系统语言。两个界面都是改动后立即切换，改动保存前就已生效。`--lang` 或 `ZCF_LANG` 会为单次运行固定语言，编辑器随之不再跟随此设置。此设置只作用于编辑器；`zcf plan` 等命令输出跟随 `--lang` 或 `ZCF_LANG`。

## 终端界面

| 按键 | 操作 |
|------|------|
| <kbd>↑</kbd> <kbd>↓</kbd>（或 <kbd>k</kbd> <kbd>j</kbd>） | 在行或页面之间移动。 |
| <kbd>Enter</kbd> | 打开页面、编辑字段、确认编辑或执行操作。 |
| <kbd>←</kbd> <kbd>→</kbd> 或 <kbd>空格</kbd> | 切换选项，例如 MCP 服务的类型。 |
| <kbd>x</kbd> | 删除选中的项目。 |
| <kbd>Esc</kbd> 或 <kbd>←</kbd> | 返回，或取消编辑。 |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | 保存。正在输入的字段请先按 <kbd>Enter</kbd> 确认。 |
| <kbd>q</kbd> | 在页面列表中退出。有未保存的修改时需按两次。 |

在“应用”页，<kbd>Enter</kbd> 执行应用，<kbd>r</kbd> 重新生成计划，方向键用于滚动。计划基于已保存的文件生成，因此有未保存的修改时，页面会提示你先保存。

MCP 服务的参数在一行中输入，规则与 shell 相同。含空格的参数需要加引号：`--header "Authorization: Bearer x"`。

## 网页界面

```bash
npx zcf ui              # 打开浏览器
npx zcf ui --no-open    # 只打印地址
npx zcf ui --port 4567  # 固定端口
```

服务器只监听 `127.0.0.1`，并且只响应发往自身地址的请求。打印出的地址以 `#token=...` 结尾。页面的每个 API 请求都会带上这个令牌，因此其他网站的页面无法通过该服务器读取或修改你的配置。服务器运行期间，请像对待密码一样对待这个地址。按 <kbd>Ctrl</kbd>+<kbd>C</kbd> 停止服务器。

浏览器会拿到配置本身，因为页面需要编辑它。计划和应用结果返回时都已遮盖：你看到的是 ZCF 所修改的每个文件的 diff，其中敏感信息已遮盖，永远不会看到整个文件。较长的密钥会保留开头 3 个和结尾 2 个字符（例如 `sk-***Xy`），方便你分辨是哪一个。

<kbd>Ctrl</kbd>+<kbd>S</kbd>（macOS 上为 <kbd>⌘</kbd>+<kbd>S</kbd>）与“保存”按钮作用相同。在同一个服务器上打开两个标签页时，每个标签页只保存自己的修改。
